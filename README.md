# MIWAYA 週間シフト自動編成

アルバイトスタッフの週間シフトを、登録した勤務可能曜日・時間帯に合わせて自動編成する静的Webアプリです。  
サーバーやデータベースは使わず、ブラウザ上で動作します。

## 起動方法

`index.html` を開くと、アプリ本体へ移動します。

GitHub Pagesなどで公開する場合も、リポジトリ直下の `index.html` を入口にできます。

## 基本の使い方

1. 「スタッフ選択」からスタッフを選びます。
2. 名前、出勤可能曜日、出勤可能時間が自動入力されます。
3. 必要に応じて曜日や時間を調整します。
4. 「スタッフを追加」を押します。
5. 必要なスタッフを登録したら「シフトを自動編成」を押します。
6. 右側の週間スケジュールと「週間合計」を確認します。

スタッフマスターを読み込めない場合や一時的に追加したい人がいる場合は、名前・曜日・時間を手入力して登録できます。

## スタッフマスターCSV

スタッフの固定データは `original/data/staff_master.csv` に登録します。

基本形式:

```csv
名前,曜日,開始,終了
スタッフA,月・火・水,17:30,24:00
スタッフB,木・金・土,18:00,23:00
```

対応している列名:

- 名前: `名前`, `スタッフ名`, `name`, `staff`, `staff_name`
- 曜日: `曜日`, `出勤曜日`, `出勤可能曜日`, `days`, `available_days`
- 開始: `開始`, `開始時刻`, `出勤開始`, `from`, `start`
- 終了: `終了`, `終了時刻`, `出勤終了`, `to`, `end`

曜日は `月・火・金`、`月火金`、`月 火 金` のような書き方に対応しています。

## シフト表示の見方

- 金色の帯: 営業時間、18:00〜23:00
- 色付きバー: 各スタッフの勤務時間
- 配置状況「2名」: 条件を満たしている時間帯
- 配置状況「不足」: 2名未満の時間帯
- 配置状況「3名」以上: 人数が多い時間帯

スマートフォンでは、曜日ごとのカード表示になります。  
元のタイムラインと同じく、30分単位の勤務バーと配置状況を確認できます。

## 初期設定

「初期設定を復元」を押すと、固定優先スタッフとして以下の設定が入ります。

- 高田（店長）
- 柴谷（専務）

固定優先スタッフは、自動編成時に先に配置されます。

## JSONでデータを共有する

このアプリは静的ホスティングで動くため、サーバー側のデータベースは使いません。  
スタッフ登録データや編成済みシフトは、JSONファイルとして書き出し・読み込みできます。

### JSONを書き出す

1. スタッフを登録します。
2. 必要に応じて「シフトを自動編成」を押します。
3. 「JSONを書き出し」を押します。
4. `miwaya-shift-YYYYMMDD.json` というファイルがダウンロードされます。
5. 画面内にJSONのプレビューが表示されます。

書き出されるJSONには、スタッフ情報、書き出し日時、編成済みシフト結果が含まれます。

### JSONを共有する

JSONを書き出すと、プレビュー欄の下に共有用のボタンが表示されます。

- 「共有する」: スマートフォンの共有画面を開きます。LINEなど、端末側で対応しているアプリを選べます。
- 「コピー」: JSON本文をクリップボードにコピーします。共有ボタンが使えない場合は、LINEなどへ貼り付けて共有してください。
- 「再ダウンロード」: 同じJSONファイルをもう一度ダウンロードします。

ブラウザや端末によっては、JSONファイルそのものではなくJSON本文の共有になる場合があります。

### JSONを読み込む

1. 「JSONを読み込み」を押します。
2. 共有された `.json` ファイルを選択します。
3. スタッフ情報がアプリに反映されます。
4. JSON内に有効なシフト結果が含まれる場合は、シフト表示も復元されます。

## JSON運用時の注意

最新版の判断は、運用上のルールで管理してください。  
同じスタッフが複数人で別々にJSONを書き出すと、どのファイルが最新か分かりづらくなるため、管理者を決める運用がおすすめです。

例:

- 管理者だけが最終版JSONを書き出す
- ファイル名に日付を入れて共有する
- 古いJSONを読み込まないように共有先でルール化する

## 自動編成のルール

- 勤務時間は17:30〜24:00の30分単位です。
- 営業時間は18:00〜23:00です。
- 常時2名体制を優先します。
- 3名体制は1日合計1時間までを目安にします。
- 一般スタッフの1勤務は最低2時間30分です。
- 週20時間を超えたスタッフは警告表示されます。

## 現在の制限

- データはブラウザのlocalStorageとJSONファイルで管理します。
- サーバー同期やログイン機能はありません。
- スタッフ情報の編集機能はまだありません。修正する場合は削除して再登録してください。
- 自動編成は条件を満たす候補を順に選ぶ方式のため、必ずしも全体最適になるとは限りません。
